# Search visibility plan

The preferred public URL is https://marshallpresson.cv/. The site provides crawlable page links, a sitemap at /sitemap.xml, robots.txt, page-specific titles and canonical URLs, and person/profile structured data. These are discovery signals, not a ranking guarantee.

## Launch checks

1. In Google Search Console, verify the domain with a DNS TXT record, submit https://marshallpresson.cv/sitemap.xml, and inspect the homepage and About page. Request indexing after verifying that the latest deployment is live. Monitor indexing, queries, clicks, and Core Web Vitals over time.
2. Configure the host to redirect HTTP and the www hostname to https://marshallpresson.cv/ and provide a valid TLS certificate for www. Test all variants before changing DNS; hosting access is required.
3. Test the About page in Google's Rich Results Test and inspect canonical URLs for the homepage, About, and project pages. Search engines choose whether to index or show enhancements.
4. Add the portfolio URL to Marshall's own GitHub, LinkedIn, Linktree and other relevant profiles. Use the same professional name and role consistently. Do not create artificial backlinks or misleading testimonials.

## Ongoing content

- Keep case studies current and explain Marshall's own contribution, technical decisions, and results; link to working demos or public repositories where appropriate.
- Verify dates, roles and numeric claims before publishing them. Replace broad claims with evidence where available.
- Publish occasional first-hand engineering notes when there is useful original experience to share; avoid automated filler or repetitive keywords.
- Review Search Console monthly and improve pages based on real queries and user needs. Indexing and ranking can take time and are not guaranteed.

References: Google's [SEO starter guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [ProfilePage documentation](https://developers.google.com/search/docs/appearance/structured-data/profile-page), and [sitemap guide](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview).
